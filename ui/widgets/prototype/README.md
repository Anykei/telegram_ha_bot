# Один HTML-документ: завершённый эксперимент

> Решение от 8 ноября 2026: единый HTML не внедряем, чтобы сохранить запас
> для расширения отдельных экранов. Рабочий бот использует отдельные HTML
> меню, графика и периода; общий исходный код и стили сохраняются.
> Этот каталог оставлен для воспроизводимости эксперимента.

Прототип проверяет переключение меню, графика, календаря и выбора времени
внутри одного документа. Меню, график, календарь и время используют один
движок, общий DOM и общие стили. Рабочий бот пока получает три компактных
артефакта, собранных из того же исходника.

## Запуск

Из корня репозитория:

```sh
npm ci --prefix ui/widgets
npm run build:prototype --prefix ui/widgets
open ui/widgets/prototype/dist/unified-preview.html
```

`open` — команда macOS; на другой системе откройте файл в браузере.
Отдельный сервер, HA и токен Telegram не нужны. Данные и ответы бота в
предпросмотре имитируются. Выбор примера в боковом списке загружает новый
тестовый сценарий; кнопки **внутри** карточки обновляют существующий документ.
Например: «Комнаты» → комната → «История: Температура» → «Период» → дата или
время → назад. Весь этот путь работает внутри одного документа.

```sh
npm run check:prototype --prefix ui/widgets
```

Для браузерных тестов нужен Chromium. На macOS используется установленный
Chromium из кеша Playwright; альтернативный путь задаётся в `HA_WIDGET_CHROME`.
Сеть в браузерном тесте отключена.

## Что проверяется

| Требование | Проверка |
|---|---|
| Внешний вид сохраняется | Геометрия, текст, цвета, шрифты и скругления каждого элемента сравниваются с рабочими шаблонами на 111 примерах, в двух темах и четырёх ширинах |
| Функции меню сохраняются | Существующий набор `release-browser.mjs`: все страницы, действия, статусы, ожидание, ошибки, подтверждения, возврат |
| График и календарь сохраняются | Существующий набор `graph-browser.mjs`: графики, даты, часы/минуты, диапазоны, PNG-команда, ошибки и навигация |
| Документ не пересоздаётся | Цепочка меню → график → период → календарь → время → график → меню сохраняет ссылки на `Document` и `Window` |
| Оба вида ответа работают | Проверяются обновление `chatData` и смена экрана непосредственно из ответа на запрос |
| Старые ответы не восстанавливают экран | Проверяются запоздалый ACK, отзыв доступа и отдельный подтверждённый возврат на главный экран |

После успешного прогона `dist/browser-report.json` содержит результаты и SHA-256
проверенного HTML. Пересборка удаляет устаревший отчёт.

## Устройство

[`src/widget.js`](../src/widget.js) содержит единственную реализацию проверки
данных, запросов, ACK, таймаутов, блокировок, темы, анимации, пагинации и
обработчиков Telegram. Вид страницы выбирает компоненты внутри этого движка.
Смена вида сбрасывает незавершённую операцию; её поздний ответ не меняет новый
экран. Ключи команд и формат данных остаются прежними.

[`src/widget.html`](../src/widget.html) — единственная оболочка: шапка, заголовок,
область графика, содержимое, навигация и обратная связь. `widget.css` задаёт
общую геометрию; `menu.css` и `media.css` — различия представлений; `graph.css`
и `range.css` — только специфичные компоненты. `widget-utilities.css` содержит
общие завершающие правила видимости и отступов около часов. Значения дизайна
берутся из существующего `design-tokens.json`.

[`compile-widget.mjs`](../compile-widget.mjs) собирает как весь интерфейс,
так и рабочие подмножества `release`, `graph`, `range`. Ненужные возможности
исключаются константами сборки; стили одного режима получают постоянные значения.
Старые отдельные движки и адаптер переключения отрисовщиков удалены.
Виртуальные пилоты `w1`/`p1` остаются отдельными демонстрациями другого протокола.

Для сравнения с сохранённой сборкой до рефакторинга можно задать
`HA_WIDGET_BASELINE_DIR`: каталог с самостоятельными `release-preview.html`,
`graph-preview.html`, `range-preview.html`. Без него сравнение использует текущие
рабочие сборки. `HA_WIDGET_PARITY_ONLY=1` запускает только сравнение внешнего вида
и переходов; обычный `check:prototype` всегда включает функциональные проверки.

## Ограничение и результат эксперимента

Точные размеры записываются в `dist/manifest.json`. Этот вариант превышает
лимит **4096 байт zlib**, поэтому является браузерным прототипом и **не подключён
к отправке в Telegram**. Внешний вид и функции не сокращались ради размера.

Сохранение `Document` в браузере подтверждает работу переключателя экранов,
но не является проверкой реального `message_id`, Telegram-клиента или HA.
Интеграция этого прототипа с ботом отменена. Проверка не означает перехода
рабочего бота на один `sendWidget` с последующими `editMessageWidgetData`.

После объединения единый HTML занимает **6700 байт zlib** вместо 8569 байт
первого прототипа (−21,8%). Рабочие подмножества: меню **4090**, график **3839**,
календарь/время **4096 байта**. Все три проходят существующий строгий лимит
сборки. Запас меню и календаря мал; каждое изменение проверяется пересборкой.
Дальнейшее сокращение единого артефакта и его внедрение не планируются.

Лимиты и неизменяемость HTML описаны в
[контракте Telegram](https://github.com/TelegramMessenger/widget-sandbox/blob/main/docs/tgw-format.md).
